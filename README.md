# E-commerce Application

This is a responsive e-commerce web application built using Angular. The application includes features such as product listing, user authentication, shopping cart functionality, and a dummy payment method.

## Features

- **Product Listing**: Users can view a list of products with images and details.
- **Product Detail**: Users can view detailed information about each product.
- **Add to Cart**: Users can add products to their shopping cart.
- **Shopping Cart**: Users can view and manage items in their cart.
- **Checkout**: Users can proceed to checkout and simulate a payment process.
- **User Authentication**: Users can log in to access certain features.

## Technologies Used

- Angular
- TypeScript
- HTML/CSS
- JSON for dummy data

## Setup Instructions

1. **Clone the repository**:
   ```bash
   git clone <repository-url>
   cd ecommerce-app
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the application**:
   ```bash
   ng serve
   ```

4. **Access the application**:
   Open your browser and navigate to `http://localhost:4200`.

## Directory Structure

- `src/app`: Contains all the application components, services, and models.
- `src/assets/data`: Contains dummy product data in JSON format.
- `src/styles.css`: Contains global styles for the application.
